# _archive

Historical, per-site copies of the Extro node client (`src/lib/extro/*`) and
the vendored engine build (`src/lib/node/pkg/`). They were superseded by the
shared `@extro/node` package (extronet/extro-node `js/`), which is the single
source for the client, codec, runtime-config parser and engine wasm.

Kept for reference only. Nothing here is imported, built, type-checked,
linted or tested; do not import from it.
